# Senior Python Engineer

We are hiring a Senior Python Engineer to build and operate our
document-matching platform.

## Responsibilities
- Design FastAPI services used by the product team
- Own deployment on AWS with Docker and Kubernetes
- Model infrastructure with Terraform
- Collaborate with the frontend team on a React upload workspace
- Keep the test suite and CI/CD pipeline in good shape

## Requirements
- Strong Python and SQL
- Experience with FastAPI, PostgreSQL and Docker
- Production experience with Kubernetes and AWS
- Familiarity with Terraform and React
- Comfortable with Git, pytest and code review
